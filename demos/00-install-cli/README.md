# Demo 00: Install CLI

The demos use `pv` to simulate typing (`brew install pv`). Without it they exit immediately; set `DEMO_MAGIC_OPTS="-n -d"` to disable simulated typing.

Run from this directory:

```sh
./demo.sh
```

Run from the repository root:

```sh
./demos/00-install-cli/demo.sh
```

Or use the npm alias from the repository root:

```sh
npm run demo:00
```
